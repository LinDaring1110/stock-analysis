# 股票利好分析 · 静态公网版

无后端、纯前端版本：数据由浏览器通过 JSONP 实时拉取**东方财富**，存到 `localStorage`，刷新按钮重新拉取并覆盖。推到 GitHub 开启 Pages 即可**公网访问**，手机随时能开。

## 目录
- `index.html` — 页面结构
- `style.css` — 暗色主题样式
- `app.js` — JSONP 拉取 + 评分排名 + 本地存储 + 刷新覆盖

## 部署到 GitHub Pages（3 步）
1. 在 GitHub 新建一个仓库（如 `stock-analysis`）。
2. 把本目录下的 **3 个文件**（index.html / style.css / app.js）上传到仓库根目录。
3. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
   - 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

> 也可让 AI 助手在你连接 GitHub 后直接帮你推送并开启 Pages。

## 功能对应需求
1. ✅ 实时筛选利好且可能上涨的股票，按利好评分（涨跌幅+主力净流入+换手率+估值）排名。
2. ✅ 双板块：上证主板 / 科创板，分别排名展示。
3. ✅ 实时资讯界面（东方财富公告，失败则衍发行情异动）。
4. ✅ 数据从网络实时获取后存本地（localStorage），刷新时重新拉取并**覆盖**更新。

## 说明
- 数据请求发生在**访问者浏览器**，因此不受本机后端限制；依赖访问者网络可访问东方财富。
- 评分为基于公开行情指标的启发式排序，仅供研究，**不构成投资建议**。
